**Descrição da vaga:**

O Cientista de Dados é responsável por coletar, tratar, analisar e interpretar grandes volumes de dados, utilizando técnicas estatísticas e modelos de Machine Learning para gerar insights que auxiliem na tomada de decisões estratégicas da empresa.

Principais atividades:
- Análise e exploração de dados;
- Criação de modelos estatísticos e preditivos;
- Aplicação de técnicas de Machine Learning;
- Comunicação dos resultados para áreas de negócio;
- Desenvolvimento de soluções baseadas em dados.

# Paradigma da Linguagem R

A linguagem **R é multiparadigma**, combinando diferentes estilos de programação.

Principais paradigmas:

- **Programação funcional** (principal): funções são tratadas como objetos, permitindo operações como composição e aplicação de funções.
- **Programação orientada a objetos (POO):** possui sistemas de objetos como S3, S4 e R6.
- **Programação procedural:** permite estruturas tradicionais como variáveis, condicionais e laços de repetição.
- **Programação orientada a dados:** muito utilizada com bibliotecas como `tidyverse`, `dplyr` e `ggplot2`.

**Resumo:**  
R é uma linguagem multiparadigma com forte influência da programação funcional e foco em estatística, análise de dados e ciência de dados.
